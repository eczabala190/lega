Para el administrador: cómo publicar esta página
  1. Generá el APK (ver README.md, sección “APK automático”) y guardalo en esta carpeta con el nombre LEGA.apk. O pegá su link en apkUrl dentro de este archivo.
  2. Subí toda la carpeta a app.netlify.com/drop (o Vercel / GitHub Pages).
  3. El link que te dan es el que compartís. Esta página muestra sola la dirección, el QR y los botones.
  4. Si usás una IP de tu red (ej. 192.168.1.20:8080), cargala en ip y se mostrará para la PC.
